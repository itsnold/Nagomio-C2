# Console Commands

## Local commands

- `help [command]`
- `clear`
- `files`
- `console`

## Remote commands

- `shell <command line>`
- `powershell <command line>`
- `sysinfo`
- `ls [path]`
- `cat <path>`
- `download <remote-path>`
- `upload <remote-destination>`
- `rm <remote-path>`
- `mv <source> <destination>`
- `mkdir <remote-path>`
- `ps`
- `kill <pid>`
- `net`

Unknown commands are passed through as raw shell execution on the selected agent.
